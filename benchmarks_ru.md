# Бенчмарки DamnScript с другими технологиями

## Lua бенчмарки

Для Lua используется популярный фреймворк MoonSharp, который позволяет использовать Lua в .NET приложениях.
Данные тесты не являются критикой Lua!
Языки используется для разных задач и имеют различный функционал, но оба очень частые гости в играх, поэтому разница
в производительности может быть важна.

## Pin бенчмарк

Для закрепления объектов в памяти используется своя реализация из-за ограничений стандартной.
Из-за того, что она не работает напрямую с GC, а использует свои методы, она работает медленнее, но избавляет от всех
ограничений стандартной реализации.

[Код](https://github.com/Rietmon/DamnScript/blob/main/DamnScriptBenchmarks/PinBenchmark.cs)
